# Cybersecurity Professional CV

This directory contains the XeLaTeX source for the Cybersecurity Professional CV v1.0.0.

## Build

```bash
make all
```

The generated PDF and extracted text are written to `compiled/`.

## Source Layout

- `cv.tex`: main LaTeX entry file
- `style/shendecv.sty`: CV style and layout definitions
- `sections/`: content sections
- `Makefile`: build commands

The public release PDF is stored at `../../releases/cybersecurity-cv-v1.0.0.pdf`.
